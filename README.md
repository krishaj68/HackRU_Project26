# RULockIn — Workload, Time Management & Study App

A collegiate workload, time management, and study time application built for hackathons, featuring Canvas Calendar integration, Gemini AI-powered task scheduling, automated study guide generation, hierarchical note organization, live exam countdowns, and distraction-free Pomodoro lockdown study sessions with retention quizzes and a companion Chrome extension.

---

## 🚀 Running on Your Computer

### Prerequisites
- **Node.js**: v18.0.0 or later (v20+ recommended)
- **npm** or **bun** / **pnpm**
- **Google Chrome** (or Chromium-based browser) for the extension component.
- (Optional) **Gemini API Key**: If you want to use live Gemini AI features locally, obtain a free API key from [Google AI Studio](https://aistudio.google.com/).

### Quick Start

1. **Unzip the downloaded archive** into any folder on your computer.
2. Open a terminal in the project folder.
